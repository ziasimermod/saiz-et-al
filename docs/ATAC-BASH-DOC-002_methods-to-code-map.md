# STAR Methods-to-code map

**Artifact ID:** ATAC-BASH-DOC-002  
**Authority used:** accepted text of `STAR Methodsv2.4_MM(1).docx` supplied on 2026-08-04.

This map separates statements explicitly supported by the STAR Methods from implementation details recovered from the historical scripts. When the two conflicted, the STAR Methods won.

## Exploratory MACS3 outputs not used downstream

MACS3 broadPeak and summit outputs were generated during exploratory batch/modality comparisons. BroadPeak intervals and standalone `_summits.bed` files were not used to define the definitive consensus peak set or count matrix because those exploratory representations showed batch-associated shifts. The downstream scripts consume only the individual-library q = 0.05 narrowPeak files.

## Explicitly not encoded in the primary Bash workflow

- Library wet-lab preparation and sequencing-core procedures.
- Differential accessibility, ComBat_seq, DESeq2, genomic annotation, enrichment, projection scores, and plotting; these belong to the R compendium.
- HOMER motif analysis; this is downstream analysis and should be added in the relevant later compendium rather than mixed into read preprocessing.
- RNA-seq or single-cell read alignment. The Methods state that public processed/count data were used for those integrations.

## Parameters that should still be verified before repository release

1. Whether an mm10 blacklist was applied to the displayed CPM browser tracks.
2. Whether `chrM` is the mitochondrial contig in the exact mm10 Bowtie2 index used for all batches.
3. Whether the deposited narrowPeak files and final 104,706-region consensus exactly match the summit-enabled individual-library calls encoded here.
